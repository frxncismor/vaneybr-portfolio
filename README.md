## 🎯 Overview

A production-ready **personal portfolio website** built for a client using the latest Angular 20 with standalone components, PrimeNG UI library, and Tailwind CSS 4. The portfolio serves as a professional showcase with content-rich sections, PDF resume export, and dynamic blog-style content with syntax highlighting.

---

## ✨ Key Features

### 🗂️ Project Showcase
- Curated portfolio section displaying the client's work and case studies
- Card-based layout with project details, technologies, and links
- Responsive grid for mobile and desktop

### 📄 PDF Resume Export
- One-click resume download generated client-side using `jsPDF`
- Formatted and styled to match the portfolio's visual identity
- No backend required — fully browser-side generation

### 📝 Markdown Content Rendering
- Blog and content sections rendered from Markdown using `marked`
- Code blocks with full syntax highlighting via `highlight.js`
- Clean typography optimized for readability

### 🎨 Modern UI/UX
- Built with **PrimeNG 20** component library for polished, accessible UI
- **Tailwind CSS 4** for custom utility-first styling
- Responsive design for mobile, tablet, and desktop
- Dark/light mode support

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/frxncismor/vaneybr-portfolio.git
cd vaneybr-portfolio
npm install
npm start
```

Open `http://localhost:4200` in your browser.

### Build for Production

```bash
npm run build
```
